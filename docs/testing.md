# 验证方式

## 无账号自动测试

`npm test` 在临时目录中测试配置与安装，不连接 ChatGPT，不发送消息。
CI 对 Node.js 22 和 24 运行相同测试及源文件语法检查。

## 真实浏览器验收（按需，使用本人的账号）

1. 安装并启动管理页，检查专用 Edge 的首次启动、手动登录和模型选择。
2. 保存配置后刷新，确认持久化；测试撤销、导入无效 JSON、导出有效配置。
3. 发一个可核对的短问题，等待完整回答，确认原聊天链接可在网页历史访问。
4. 同一请求 ID 重新查询不得重复发送；页面刷新后可恢复记录。
5. 测试按任务复用、新建聊天及跨任务复用，核对聊天链接和首条提示词。
6. 切换账号确实可用的另一个模型，核对页面标签；无此模型则记录未验证。
7. 暂停咨询后确认无法提交。恢复设置，关闭专用 Edge 后再次启动。
8. 窄屏检查页面无横向溢出。结束后恢复个人偏好。

不要用 CI 保存浏览器登录资料，也不要自动登录、绕过验证码或在无人知情时发送测试消息。

## 界面双语验收

专用 Edge 的本机调试端口可用时运行 `node tests/i18n-browser.mjs`。测试会创建临时本地 HTTP 服务和单独标签页，使用模拟问答数据，不请求 ChatGPT；完成后关闭自己的标签页，并更新文档中的示例截图。检查语言记忆、未保存内容保留、问答原文保留及桌面和窄屏布局。
